# How to Create a Pull Request
## Introduction
A pull request is request to the maintainers of a project to review and changes you made into the project codebase
## Steps
1. Create a new branch for your changes.
2. Make the necessary changes to the project.
3. Commit your changes to the branch.
4. Push the branch to Github.
5. Open the repository on Github.
6. Click **Pull request**.
7. Click **New Pull request**.
8. Select the branch as the branch containing your changes and the main branch as the base branch.
9. Review the changes and add a clear title a description.
10. Click **Create pull request**.

## Conclusion
A pull request allows project maintainers and contributors to review changes before they are merged into the project

## Before Submitting a Pull Request

Before submitting a pull request, make sure you:

- Review your changes for errors.
- Make sure the changes solve the intended problem.
- Write a clear pull request title and description.
- Check that your changes do not introduce unnecessary changes.
- Test the instructions to make sure they work as expected.
